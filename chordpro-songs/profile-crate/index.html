ChordPro Songs & Setlists

The profile specifies metadata for a songbook harvested from a folder of ChordPro song charts (.cho/.pro) and Markdown setlists (.setlist.md).

A song file is described as a MusicComposition with a copy of its ChordPro source in a text property.

Setlists are described using MusicPlaylist, to list the songs for a particular event, optionally divided in sets, via a nested MusicPlaylist. MusicPlaylist enties may also have parts that are MusicComposition entries which are specializations of a song, referenced via specializationOf, which may have their own key and capo information

Properties

  • composer — The person or organization who wrote a composition, or who is the composer of a work performed at some event.
  • datePublished — Date of first publication or broadcast. For example the date a [[CreativeWork]] was broadcast or a [[Certification]] was issued.
  • description — A description of the item.
  • hasPart — Indicates an item or CreativeWork that is part of this item, or CreativeWork (in some sense).
  • license — A license document that applies to this content, typically indicated by URL.
  • musicalKey — The key, mode, or scale this composition uses.
  • name — The songbook's own title. #name-Dataset
  • name — A top-level setlist's own title (e.g. "Friday Gig"), or — on a nested "#" set — that set's own heading text (e.g. "Set 1"); MusicPlaylist covers both (SPEC.md §6). #name-MusicPlaylist
  • name — A canonical song's own title. #name-MusicCompositionSong
  • name — The raw heading text for this setlist entry, taken verbatim from the setlist file — may be a fuzzy or approximate match to the song it specializes, not necessarily identical to that song's own name. #name-MusicCompositionSongProxy
  • performer — A performer at the event—for example, a presenter, musician, musical group or actor.
  • specializationOf — chordpro-input's own use: links a setlist-entry MusicCompositionSongProxy to the canonical MusicCompositionSong it performs.
  • subtitle — A secondary title for the item — chordpro-input's own use: a song's {subtitle}/{st} ChordPro directive.
  • text — The song's own verbatim ChordPro source (directives and all) — the one place its full text lives; every setlist entry that performs it points back here rather than carrying its own copy. #text-MusicCompositionSong
  • text — This entry's own short performance note, written as Markdown and rendered as such — optional; absent on most entries. Never the song's own text, which lives on the MusicCompositionSong it specializes instead. #text-MusicCompositionSongProxy
  • text — A setlist's or a "#" set's own freeform note, written as Markdown and rendered as such — optional; the freeform text found between a "#" heading and its first entry, or authored anywhere for a top-level setlist. #text-MusicPlaylist
